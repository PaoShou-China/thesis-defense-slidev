# 学术 PPT 内容要求

内容已整理成可逐页执行的检查表，包含章节级要求、页面验收标准、时间分配和工科博士答辩适配。

[阅读完整教程提炼与审查判据](../skills/thesis-defense-slide-review/references/academic-presentation-content.md)

核心检查：全篇核心信息是否清楚；每页是否围绕一个观点；证据是否直接支持标题；方法与背景是否服务于主线；多项工作是否有明确联系；图表是否容易解读；贡献与已有工作是否区分；细节是否合理进入备份页。

## 按博士论文汇报章节拆解的细化要求

下面的要求用于审稿、写稿和逐页批改。每一节都要完成“主张—证据—承接”三件事；若某项没有材料支持，应标记为“待补证据”，不能用形容词代替。

### 1. 研究背景与意义

- **先定义对象**：用一句话交代研究对象、应用场景、工况或任务边界；不要从过宽的行业口号开始。
- **再说明矛盾**：给出一个可观察的工程现象、性能瓶颈或安全/成本约束，并说明它为什么影响系统目标。
- **最后落到必要性**：把背景事实收束成“如果不解决，会造成什么后果”；意义分为科学问题、工程价值和应用边界，避免只写“具有重要意义”。
- **图页要求**：至少有一张对象/场景图或数据图；图旁必须写出读图结论。背景页不能只放概念云图和口号。
- **过关标准**：听众看完能回答“研究什么、为什么现在要研究、成功要改善什么指标”。

### 2. 国内外研究现状与发展趋势

- **按问题或能力分类**：建议按模型、算法、控制/系统、实验验证等能力组织，而不是按国家或作者流水账罗列。
- **每类至少三句**：已有方法解决了什么；依赖什么假设或条件；在什么场景下仍然不足。
- **比较必须同口径**：表格明确比较对象、数据/工况、指标、优势和限制；没有可比证据时，不写“优于”。
- **趋势要有依据**：趋势应由近年方法演进、应用需求或指标变化推出，不能把“智能化、融合化”等词当作趋势证据。
- **综述收束**：结尾必须形成 1–3 个具体研究缺口，并逐一连接到后面的研究目标；不能以“因此有必要研究”结束。
- **避免误区**：不把文献数量当现状深度；不把论文标题、机构名称和年份堆在页面上；不把自己的方法提前写成已被证明的结论。

### 3. 研究问题、目标与科学/工程问题

- **问题写成可检验句子**：包含对象、条件、待解释或待优化变量和评价指标，例如“在 X 扰动下，如何降低 Y 误差并保持 Z 约束”。
- **区分三层问题**：现象问题（发生了什么）、机制问题（为什么发生）、工程问题（怎样在约束下解决）。
- **目标可验收**：每个目标对应一个指标、定理性质、实验任务或交付物；避免“建立体系、提高水平”这类不可验收表述。
- **边界先写清**：说明研究不覆盖的工况、数据、对象和假设，防止后文结论被过度解读。
- **目标—工作映射**：用编号将问题 Q1/Q2/Q3 映射到研究工作 W1/W2/W3、验证 V1/V2/V3。

### 4. 总体技术路线与论文结构

- **路线是因果链**：问题 → 建模/理论 → 方法 → 实现 → 验证 → 结论；箭头旁写输入、输出或判据，不只画模块框。
- **说明工作之间的关系**：标出前置依赖、共享数据/平台、独立子问题和综合验证；解释为什么这些工作共同构成一篇博士论文。
- **标出闭环**：每项研究工作都要回到一个目标和一个证据出口；路线图中不应出现没有后续验证的孤立模块。
- **论文结构页**：章节名称使用与正文一致的术语；研究内容页不要把目录重复一遍，要交代每章承担的论证角色。

### 5. 主要研究工作（每项工作采用同一小结构）

每项工作至少用“问题—方法—关键结果—小结”四页或四个区块讲清楚：

- **问题**：本项工作承接哪个缺口，输入和约束是什么。
- **方法**：只保留理解创新所需的模型、算法、系统结构和关键设计理由；定义符号、变量和假设。
- **结果**：优先展示能验证该项工作主张的对照或消融结果，写明工况、基线、指标和重复方式。
- **小结**：一句话回答“本项工作解决了什么、证据是什么、还留下什么边界”。
- **技术深度**：工科博士汇报应让评委判断方法为何成立、何时失效、怎样实现；冗长推导、参数全集和代码放备份页。
- **本人贡献**：合作研究要明确本人负责的问题、设计、实现和验证部分。

### 6. 实验、仿真与结果分析

- **实验设置先于结果**：说明数据来源、样本/工况、设备或仿真环境、基线、参数、评价指标、重复次数和统计口径。
- **验证分层**：明确区分数值仿真、公开数据、硬件在环、台架和实物实验；不要用仿真结果替代工程可行性证据。
- **公平对照**：比较方法使用相同数据、预算、约束和停止条件；若不能完全一致，说明差异及影响。
- **结果页写结论标题**：标题直接写本页得到的结论；图中突出差异，正文解释差异是否具有统计或工程意义。
- **不只报最好值**：同时报告平均/中位数、离散程度、置信区间或重复结果；说明异常值、失败工况和负面结果。
- **结果到结论**：每个结论都能在图表中定位；避免从单一工况外推到全部场景。
- **工程价值**：说明改进幅度对应的成本、实时性、资源、稳定性或安全影响，不能只报百分比。

### 7. 创新点与主要贡献

- **按贡献类型分层**：理论/模型、方法/算法、系统/工程、验证/数据四类可按实际取舍。
- **使用三段式**：针对什么具体缺口；提出了什么可复述的关键做法；由哪项证据证明带来什么改进。
- **逐项对应证据**：贡献编号 C1/C2/C3 必须能回指研究工作、图表或定理；“首次、国际领先、显著”只有在有充分比较依据时使用。
- **区分创新与工作量**：系统集成、参数调试和常规实验可以是必要工作，但不自动构成创新。
- **说明适用边界**：贡献后附条件、局限或尚未验证的范围，增强可信度。

### 8. 总结、局限与展望

- **总结不是目录复述**：按“问题—方法—证据—结论”逐项回收主线，并给出最重要的定量结果或理论性质。
- **局限具体可验证**：指出数据、模型、工况、泛化、实时性、成本或安全方面的限制，并说明限制如何影响结论。
- **展望是下一步问题**：每条展望对应一个当前局限和可执行路线，避免写成泛泛的“进一步研究”。
- **最后一页留问答空间**：保留题目、姓名和联系方式；备份页准备关键参数、补充实验、证明或对比细节。

### 9. 时间与页数检查

- 先按答辩通知确定总时长，再按章节分配讲述时间；博士答辩常见要求为 40–45 分钟，但以学校和学院通知为准。
- 每页只承担一个主讲动作；连续出现公式、表格或密集图页时，预留解释时间。
- 练习时记录“实际讲述时间、被跳过页面、无法一句话说清的页面”；超时优先删背景重复和次要推导，不删核心证据。
- 主讲页展示结论和必要证据，备份页承担评委追问；目录页不应挤占研究论证时间。

### 10. 逐页验收表

| 检查项 | 合格判据 |
| --- | --- |
| 本页主张 | 能用一句完整句子说清，不是“研究内容/实验结果”等泛标题 |
| 证据 | 图表、公式、案例或数据直接支撑主张，来源和口径明确 |
| 承接 | 能说明为什么从上一页来到本页、下一页将解决什么 |
| 可读性 | 投影距离下文字、坐标、图例和单位可读，重点有视觉层级 |
| 可答辩性 | 对假设、基线、参数、边界和本人贡献有可追溯回答 |
| 真实性 | 没有把教学示例、推测或未验证结果写成论文结论 |

## 字号、重点与总结句硬性要求

### 字号下限

- **普通正文、表格、图注、页码、章节号和图例**：默认不低于 **20 pt**；正文原则上使用 22–26 pt。
- **页面标题**：不低于 **30 pt**；章节过渡标题可更大，但不能通过挤压正文来实现。
- **关键数字、结论和重点标注**：不低于 **24 pt**，并用位置、粗细或模板红色建立层级。
- **坐标轴、单位、数据标签**：不低于 **20 pt**。如果图表因此放不下，应删减曲线、拆分图表或移入备份页，不能缩小到看不清。
- **硬性判定**：投影预览或后排距离下看不清的字一律不能放入主讲页；字号低于上述下限且没有明确特殊理由，至少判为 P1，影响核心证据时判为 P0。
- **不以设备截图代替验收**：必须按实际 16:9 页面、投影距离和导出文件检查；浏览器缩放后看清不算合格。

### 每页重点

除封面、目录、章节过渡和致谢页外，每一页必须有一个视觉上最先被看到的重点：

- 重点可以是一个结论数字、一条关键曲线、一个机制、一个公式中的核心关系或一项对比结果。
- 重点应通过标题结论、红色强调、加粗、标注框、箭头或留白突出；不能让所有文字和图形处于同一视觉权重。
- 一页出现两个以上同等重点时，应拆页或明确主次；不能用整页加粗解决层级问题。

### 每页总结句

每一张内容页必须有一句放在页面底部或结论区的**总结句/Takeaway**，用完整句回答“这一页希望评委记住什么”。

- 总结句必须由本页内容直接支持，不能写成口号或重复标题。
- 方法页总结“方法解决了什么、依赖什么条件”；结果页总结“在什么工况下得到什么结果”；现状页总结“缺口是什么”；背景页总结“为什么必须研究”。
- 总结句建议 22–26 pt，并与主体内容保持明显层级差异。
- 若一句话无法写清本页结论，说明页面承担了过多任务，应拆页或调整内容。
- 目录、章节过渡和致谢页可使用导航句、承接句或问答提示替代研究总结句，但也必须有明确的页面功能提示。

### 批改动作

逐页记录三项：**最重要的视觉元素｜页面总结句｜最小字号**。任意一项缺失，都不能标记为“通过”。优先修改顺序为：先删除或拆分超量内容，再重排重点，最后统一字号；不能先缩小字体再迁就内容。
