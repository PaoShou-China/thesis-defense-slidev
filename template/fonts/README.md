# 字体说明

模板已经把所有普通文字指定为 `Microsoft YaHei`（微软雅黑），包括标题、正文、表格、图注、数字和页码。

微软雅黑属于 Windows 系统字体，不能直接随公开仓库重新分发。因此仓库不包含字体二进制文件。Windows 用户通常无需额外安装；如果系统没有该字体，请先安装微软雅黑，再运行 Slidev 或导出 PPTX。

构建/截图环境必须实际装有微软雅黑，才可验收字体。浏览器开发者工具可检查计算字体，但 `font-family` 列表本身只表示请求，不代表已命中。Windows 上可运行 `fc-match 'Microsoft YaHei'`（安装 fontconfig 时）或在 PowerPoint 字体替换中确认；未命中时记录为 fallback，并在目标设备重新导出检查。普通文字使用微软雅黑加粗，公式继续使用数学字体以保证上下标、希腊字母和算符正常显示。
