# Slidev 工科答辩模板

按照所附 PDF 重建 16∶9 蓝红学术版式。保留白底、深蓝标题、红色关键词、蓝色编号、横线、左蓝右白目录及封面曲线。未复用人物照片、校徽或建筑图。示例内容均为占位，不是实际研究成果。

## 运行

安装 Node.js 22.12+，进入解压目录：

```bash
npm install
npm run dev
```

`npm run build` 构建静态网页。`npm run export` 导出 PDF（可能需要安装 Playwright Chromium）。

## 文件

- slides.md：12 页示例内容与页面配置。
- style.css：统一配色、字号与间距。
- layouts/default.vue：普通内容页，章节号与页码自动生成。
- layouts/cover.vue：封面与致谢。
- layouts/agenda.vue：目录及章节过渡。
- public/：放置本地图片。

## 修改

普通页面通过 section、heading、emphasis 设置章节编号、蓝色主标题和红色重点。封面通过 presenter、institute、supervisor、date 设置人员及日期。

图片示例：`<img src="/example.png" alt="研究对象">`。图片文件放 public 文件夹，可替换 figure 占位框。公式使用双美元符号，使用标准 LaTeX。内容拥挤时拆页，不通过持续缩小字号解决。

标题、正文、数字、图注和页码统一指定微软雅黑，需在运行及导出设备安装。公式保留数学字体。环境缺少微软雅黑时，浏览器回退结果不属于本模板的字体验收效果。参考稿的部分页面含空白区，模板将这些区域改成图文占位，不复刻空白内容。
