# 西红柿炒鸡蛋科研汇报示例

默认入口为模板目录的 `slides.md`，共 22 页，示范背景、现状、定义、方法、对照、消融、讨论和结论的组织方式。通用空白示例已保留为 `starter.md`。

## 查看与运行

在 `template` 目录执行 `npm ci`、`npm run dev`。使用通用示例执行 `npm run dev:starter`。

## 复现实验

在 `template` 目录执行：

```bash
python examples/tomato/simulate.py
```

脚本只使用 Python 标准库，生成 800 行测试记录（200 个批次、4 种方法）、汇总指标和 SVG 图。脚本可直接查看，全部 SVG 可在 GitHub 在线预览。

模型定义：z1=u1/m，z2=u2/m，目标为 (0.8,0.3)。m 均匀采样于 [0.65,1.35]，估计为 m 加标准差 0.03 的高斯噪声，下限为0.1。RMSE 是二维误差范数的均方根，P95 是排序后第190个样本值。所有方法共用同一批扰动与估计值。

这是一份原创教学演绎，以网上常见的番茄炒蛋科研类比为题材，没有复制原网文的情节或虚构论文。数据是合成模型的计算结果，不能用作真实试吃、烹饪工艺或食品科学结论。程序没有温度、火候或营养模型。

## PowerPoint 文件

`tomato-research.pptx` 为 Slidev 可编辑模式导出的 22 页演示。标题、正文和多数形状可编辑，公式与部分图形保留为图片。普通文字指定微软雅黑，需本机安装；跨软件打开后请检查换行与图形位置。
